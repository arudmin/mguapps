# Игры для BMW MGU Store: Flappy Bird и Chrome Dino

Репозиторий содержит два отдельных игровых приложения для мультимедийной системы BMW MGU (iDrive 7/8):

| Игра | Папка | Описание |
| --- | --- | --- |
| **Flappy Bird** | `apps/flappy_bird/` | Аркада с птицей: пролетайте между препятствиями. |
| **Chrome Dino** | `apps/chrome_dino/` | Игра с пиксельным динозавром: прыгайте через кактусы и избегайте птиц. Версия 1.4.2: увеличенный динозавр, сложности Easy / Normal / Hard / Extreme. |

**Внимание:** в данном ZIP находится только приложение `chrome_dino` и этот README для размещения в корне GitHub-репозитория. Исходники Flappy Bird остаются в вашем существующем репозитории; этот архив их не заменяет.

## Как добавить игры в GitHub

1. Откройте свой репозиторий с приложениями MGU Store.
2. Разместите папку `chrome_dino` из этого ZIP по пути `apps/chrome_dino/` (файлы `app.json`, `build.js`, `package/`, `icon.png`, `release.json` должны лежать внутри неё).
3. Не удаляйте уже существующую папку `apps/flappy_bird/`.
4. Скопируйте этот `README.md` в корень репозитория.
5. Зафиксируйте изменения и отправьте их в GitHub.

## Как установить через MGU Store

1. Убедитесь, что MGU Store уже установлен и функционирует на вашем BMW. Автомобиль должен быть припаркован.
2. В MGU Store откройте раздел управления каталогами/репозиториями и добавьте URL своего GitHub-репозитория с приложениями, если он ещё не добавлен.
3. Обновите список приложений в магазине.
4. Выберите **Flappy Bird** или **Chrome Dino** и установите нужную игру отдельно. Доступность пунктов меню может зависеть от конкретной версии MGU Store.
5. Запустите игру через меню приложений BMW.

Если магазин не видит приложение, проверьте структуру `apps/<id>/`, `app.json`, наличие `build.js`, а также совместимость вашего MGU Store. Простое копирование ZIP в головное устройство не является способом установки.

## Управление Chrome Dino

- Нажатие контроллера iDrive — начать игру или прыгнуть.
- BACK — вернуться в меню.
- Difficulty — переключение Easy → Normal → Hard → Extreme.
- Restart — начать забег заново.

**Играть только на стоянке.** Запуск ограничивается проверкой скорости автомобиля.

## Локальная проверка и сборка Chrome Dino

Из корня репозитория:

```bash
node apps/chrome_dino/build.js --preview-only
node apps/chrome_dino/build.js
```

Готовый OAP-пакет создаётся по адресу `apps/chrome_dino/dist/chrome_dino@1.4.2.tgz`. Сборщик работает на Node.js без npm и без скачивания SDK. Папку `dist/` в GitHub можно не публиковать: при установке магазин собирает приложение по исходникам при наличии поддержки данного формата.

Офлайн-проверки выполнены, но установку этой версии на физическом BMW необходимо подтвердить отдельно.


Исправление 1.4.2: стандартная прозрачная иконка без стеклянной плитки; размер приведён к формату MGU Store.


### Chrome Dino 1.4.2
- Динозавр в оригинальных пиксельных пропорциях Chrome T-Rex (контур восстановлен по образцу).
- Кактусы в стиле оригинала: большие, маленькие, группы из 2–3 с отдельными хитбоксами.
- Сложности различаются плотностью и составом препятствий, а не только скоростью.
- Бесполезная кнопка Restart убрана из меню: после проигрыша нажмите контроллер для новой попытки.
- Играть только на стоящем автомобиле.
