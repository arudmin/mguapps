# Игры для BMW MGU Store: Flappy Bird и Chrome Dino

Репозиторий содержит два отдельных игровых приложения для мультимедийной системы BMW MGU (iDrive 7/8):

| Игра | Папка | Описание |
| --- | --- | --- |
| **Flappy Bird** | `apps/flappy_bird/` | Аркада с птицей: пролетайте между препятствиями. |
| **Chrome Dino** | `apps/chrome_dino/` | Игра с пиксельным динозавром: прыгайте через кактусы и избегайте птиц. Версия 1.5.7 в top-chart: новый Dashboard, четыре сложности и локальные рекорды. [Документация](apps/chrome_dino/README.md). |

## Как установить через MGU Store

1. Убедитесь, что MGU Store уже установлен и функционирует на вашем BMW. Автомобиль должен быть припаркован.
2. В MGU Store откройте раздел управления каталогами/репозиториями и добавьте этот репозиторий `arudmin/mguapps` и выберите нужную ветку. Для версии 1.5.7 используйте https://github.com/arudmin/mguapps/tree/top-chart.
3. Обновите список приложений в магазине.
4. Выберите **Flappy Bird** или **Chrome Dino** и установите нужную игру отдельно. Доступность пунктов меню может зависеть от конкретной версии MGU Store.
5. Запустите игру через меню приложений BMW.

## Управление в игре

- Нажатие контроллера iDrive — начать игру или прыгнуть.
- До начала забега вращайте контроллер для выбора PLAY, сложности или языка; нажмите для активации.
- На сенсорном экране нажимайте правые строки сложности и языка или игровое поле для старта/прыжка.
- Сложность: Easy → Normal → Hard → Extreme. После проигрыша можно начать новый забег.

**Играть только на стоянке.** Запуск ограничивается проверкой скорости автомобиля.

## Chrome Dino 1.5.7 — актуальная версия разработки

- Новый Dashboard в автомобильном стиле: игровое поле слева, счёт, личный рекорд, сложность, язык и FPS справа. Старое меню не используется для управления; его RHMI-ресурсы сохранены для совместимости.
- Четыре уровня: Easy, Normal, Hard, Extreme. Различаются скорость, ускорение, высота прыжка, частота птиц и групп кактусов, интервалы препятствий. Normal получил более высокий прыжок и увеличенные интервалы относительно предыдущего варианта; Hard имеет на 20% меньшие начальную/максимальную скорость и ускорение, чем Extreme.
- Оригинальный пиксельный силуэт T-Rex, два кадра бега, поза прыжка, одиночные и групповые кактусы, птицы.
- Отдельные локальные рекорды для каждой сложности; миграция прежних рекордов Normal → Easy.
- Автоматический язык BMW через HMIContext и 12 ручных языков: русский, английский, немецкий, испанский, французский, итальянский, португальский, нидерландский, польский, украинский, китайский, японский.
- GPU-отрисовка до 60 Гц, счётчик частоты подготовки кадров; программный PNG-режим — 8 Гц. Физика с фиксированным шагом 1/120 с. Реальные 60 FPS на BMW пока не гарантированы.
- Поддержка контроллера iDrive и сенсорного управления, блокировка игры при ненулевой, неизвестной или устаревшей скорости.
- Исправление ошибки запуска 1.5.4 (необъявленная переменная visualTheme), удаление устаревших обработчиков меню и настройки Classic, сброс счётчика FPS при изменении состояния безопасности.
- Независимая офлайн-сборка OAP без скачивания BMW SDK; проверка обновлений по публичному app.json ветки main без передачи VIN.
- GitHub Actions: проверка синтаксиса и неопределённых переменных, тесты запуска ID7/ID8 с имитацией MGU, физики, локализации, безопасности и сборки по контракту MGU Store; восемь SVG-превью Dashboard, диагностические логи и SHA-256 пакета. [CI №50](https://github.com/arudmin/mguapps/actions/runs/45344295643) для кода 1.5.7 завершён успешно. Установка и FPS на физическом BMW требуют отдельной проверки.

**Онлайн-рейтинг:** в папке [leaderboard](apps/chrome_dino/leaderboard/README.md) находится экспериментальный серверный код и клиентский модуль. В игру они пока не интегрированы; действующего глобального рейтинга нет.

Подробная [история версий Chrome Dino](apps/chrome_dino/README.md#история-версий).

**Leaderboard server 0.1.0 (24.11.2026, staging):** добавлен серверный HMAC поверх локального SHA-256 VIN, никнейм user_ + 8 символов HMAC, отдельный токен авторизации, четыре режима, сессии и одноразовая отправка результата. Результаты остаются pending до реализации проверки повторов. Добавлены SQL/API-тесты и автоматическое развёртывание Cloudflare Workers/D1 через GitHub Secrets. Интерфейс BMW не интегрирован, версия игры 1.5.7 не изменена. Статус развёртывания подтверждается отдельным CI. [Документация сервера](apps/chrome_dino/leaderboard/README.md).

## Локальная проверка и сборка

Из корня репозитория:

```bash
node apps/chrome_dino/build.js --preview-only
node apps/chrome_dino/build.js
```

Пакет: `apps/chrome_dino/dist/chrome_dino@1.5.7.tgz`. При установке из ветки MGU Store запускает сборщик по `mgu-repo.json`; артефакты Actions предназначены для тестирования и диагностики, а не являются автоматически опубликованными релизами.
