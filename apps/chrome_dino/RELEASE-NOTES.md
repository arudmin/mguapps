## Chrome Dino 1.5.36 · BMW iDrive 7/8

- Восстановление прежнего имени и рекордов всех четырёх сложностей после переустановки. Более высокие локальные результаты сохраняются.
- Отдельное окно восстановления с поддержкой сенсорного экрана, контроллера iDrive и 12 языков. При потере связи можно играть офлайн.
- Сервер 0.2.13 сохраняет прежние профили и совместимость API v1. Для старого профиля без кода предусмотрена адресная временная выдача администратором.

Сохраните код через **Топ игроков → Профиль** перед удалением игры. Тесты на имитации ID7/ID8 не заменяют проверку на физическом BMW. [SDD](https://github.com/arudmin/mguapps/blob/main/apps/chrome_dino/SDD.md)
