# Chrome Dino 1.4.4 для BMW MGU Store

Самостоятельное приложение для BMW MGU, iDrive 7/8. Игра запускается только при остановленном автомобиле.

## Что нового в версии 1.4.4

- Увеличенный пиксельный T-Rex, лучше различимый на экране iDrive.
- Выбор из четырёх сложностей **Easy**, **Normal**, **Hard**, **Extreme** в главном меню.
- Повышенная скорость, ускорение и частота препятствий на высоких сложностях.
- Обновлённая слегка полупрозрачная иконка.

## Управление

- Нажать контроллер iDrive — начать игру / прыжок.
- `BACK` — вернуться в меню.
- `Difficulty` — переключать сложности.
- `Restart` — начать заново.

## Установка

Поместите **эту папку** как `apps/chrome_dino/` в ваш GitHub-репозиторий, подключённый к MGU Store. Обновите каталог в MGU Store и выберите Chrome Dino. Не требуется предварительно устанавливать Flappy Bird.

## Сборка и проверка

Из корня GitHub-репозитория:

```bash
node apps/chrome_dino/build.js --preview-only
node apps/chrome_dino/build.js
```

В этой папке также содержится полный собранный пакет `dist/chrome_dino@1.4.4.tgz`. Для публикации исходников в GitHub `dist/` можно исключить. BMW SDK отдельно устанавливать не нужно: необходимые сервисы предоставляет MGU Store/головное устройство.

Офлайн-проверка выполнена; установка на реальном автомобиле не проверялась.


Исправление 1.4.4: стандартная прозрачная иконка без стеклянной плитки; размер приведён к формату MGU Store.


### Chrome Dino 1.4.4
- Динозавр в оригинальных пиксельных пропорциях Chrome T-Rex (контур восстановлен по образцу).
- Кактусы в стиле оригинала: большие, маленькие, группы из 2–3 с отдельными хитбоксами.
- Сложности различаются плотностью и составом препятствий, а не только скоростью.
- Бесполезная кнопка Restart убрана из меню: после проигрыша нажмите контроллер для новой попытки.
- Играть только на стоящем автомобиле.


## Локализация Chrome Dino 1.4.4

Меню автоматически определяет язык головного устройства через HMIContext/HMIContext2 (`currentDisplayLanguage`) и реагирует на смену языка. Есть переводы на русский, английский, немецкий, французский, испанский, итальянский, португальский, польский, украинский, нидерландский, шведский и турецкий. Если язык недоступен или не поддержан, используется английский. Игровые надписи на графическом экране пока остаются английскими.
